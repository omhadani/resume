מומחה תמיכה טכנית ומיישם מערכות CRM

תקציר מקצועי

מיישם ותומך טכני מיומן עם ניסיון של למעלה מ-15 שנה בהטמעה,יישום וניהול ופתרון תקלות במערכות מידע ומערכות CRM, כולל HubSpot ו-Salesforce. בעל ניסיון מוכח בפתרון אתגרים טכניים מורכבים וייעול תהליכי עבודה תפעוליים. שולט בכתיבת שאילתות SQL מתקדמות, אינטגרציות API וניתוח נתונים. מחפש באופן פעיל תפקיד דינמי בו אוכל למנף את המומחיות הטכנית שלי, כלי בינה מלאכותית וחשיבה חדשנית לקידום צמיחה עסקית ולעידוד שיפור מתמיד.

יישום תמיכה טכנית | SilverNet Financial Systems

אוגוסט 2023 – הווה

SilverNet (חלק מקבוצת Malamteam) מספקת פתרונות פיננסיים מתקדמים לבנקאות ולאוצר תאגידי.

●        ניהול, תיאום וביצוע פרויקטים מול לקוחות ומוסדות בנקאיים, תוך עבודה שוטפת מול גורמים מקצועיים, מעקב אחר תהליכים ולוחות זמנים ומתן מענה שוטף לצורכי הלקוח.

●        מתן תמיכה רב-ערוצית (דוא"ל, טלפון וצ'אט) לחברות המובילות בישראל, תוך הבטחת פתרון מהיר ויעיל של פניות לקוחות.

●        ניהול היקף גבוה של קריאות תמיכה, תעדוף ופתרון סוגיות מורכבות בהתאם להסכמי רמת שירות (SLA) מחמירים באמצעות מערכת קריאות שירות מקיפה.

●        שימוש בטכניקות פתרון תקלות תוך שימוש ב SQL וממשקי API לפתרון אתגרים טכניים, והסלמת סוגיות לצוותים פנימיים בעת הצורך להבטחת רציפות השירות.

●        חקירת לוגים בשרת לצורך איתור מקור התקלה ופתרונה ביעילות.

●        רקע נרחב בהטמעת מערכות מידע ותהליכי CRM, כולל הגדרת תהליכי עבודה, קונפיגורציה של מערכות ואינטגרציה בין מערכות ארגוניות.

●        תיעוד פתרונות ושיטות עבודה מומלצות לשיפור יעילות הצוות, תוך פיתוח בסיס ידע וכלי תמיכה מבוססי בינה מלאכותית לשיפור מתמיד.
